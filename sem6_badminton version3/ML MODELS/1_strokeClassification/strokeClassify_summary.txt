🧠 3. FEATURE ENGINEERING (PYTHON ONLY)

From ESP32 swing-summary data, we compute:

🔵 CORE FEATURES
peak_acc
peak_gyro
duration
acc_mag_mean
gyro_mag_mean
🧠 ENGINEERED FEATURES (XGBOOST POWER FEATURES)
⚡ Explosiveness
SPI = peak_gyro · log(1 + peak_acc)
explosive_energy = peak_acc · peak_gyro · duration
impact_ratio = peak_acc / (peak_gyro + ε)
🏎 Speed & Efficiency
acc_efficiency = peak_acc / duration
gyro_efficiency = peak_gyro / duration
control_index = acc_mag_mean / (gyro_mag_mean + ε)
🎯 Swing Signature
burst_acc = peak_acc / (acc_mag_mean + ε)
burst_gyro = peak_gyro / (gyro_mag_mean + ε)
shape_ratio = (peak_gyro · duration) / (peak_acc + ε)
🧠 Stability Metrics
aggression = (peak_acc + peak_gyro) · duration
smoothness = (acc_mag_mean + gyro_mag_mean) / (peak_acc + peak_gyro + ε)
